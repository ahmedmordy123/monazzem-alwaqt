# منظم الوقت

مؤقت مكعب لويندوز — هدية مجانية.

## تحميل

نزّل المثبت من صفحة الإصدارات:
https://github.com/ahmedmordy123/monazzem-alwaqt/releases/latest

الملف: `flip-cube-timer-setup.exe`

### التثبيت
1. ويندوز 10 أو 11 (64-bit)
2. دابل كليك على المثبت
3. لو ظهر SmartScreen: More info → Run anyway
4. بعد التثبيت افتح **منظم الوقت** من قائمة ابدأ

الكود المصدري غير منشور هنا؛ هذا المستودع للتوزيع فقط.
