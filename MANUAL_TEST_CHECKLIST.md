# Manual tablet checklist / قائمة الفحص اليدوي

Max 15 items — Spacedesk tablet + primary PC.

## English

1. Install app; launch on Spacedesk tablet full-screen (Desk Cube).
2. Cube silhouette centered; no obvious corner notches at rest (white + black themes).
3. Swipe flip feels OK; countdown starts after settle; blue LED on while running.
4. Tap pauses; tap again resumes; remaining time looks correct.
5. Long-press resets to full face duration (Idle, not running).
6. Flip while running restarts with the new face’s duration.
7. Custom face: set 1 min in Settings; run to finish; hear/see notification + LED flash.
8. Sleep PC ~30s while Running; wake — remaining reflects real elapsed time (or Finished).
9. Kill process mid-run; relaunch — timer restores remaining correctly.
10. Disconnect Spacedesk; window moves to primary without losing timer; reconnect — returns.
11. Widget mode (~220²): always-on-top, draggable, position remembered; hotkey toggles mode.
12. Tray shows remaining; Pause/Reset/Quit work; minimize-to-tray OK.
13. Global hotkeys work while another app is focused.
14. Arabic UI: RTL settings/tray; Western digits on LED.
15. Idle CPU ~0%; no crash after 10+ flips.

## العربية

1. ثبّت التطبيق وافتحه على شاشة Spacedesk (وضع المكتب).
2. المكعب في الوسط؛ لا فجوات واضحة في الزوايا (أبيض/أسود).
3. السحب يقلب المكعب ويبدأ العد بعد الاستقرار؛ LED أزرق أثناء التشغيل.
4. النقر يوقف مؤقتاً ثم يستأنف؛ الوقت المتبقي صحيح.
5. الضغط الطويل يعيد المدة كاملة (وضع Idle).
6. القلب أثناء التشغيل يعيد البدء بمدة الوجه الجديد.
7. وجه مخصص دقيقة واحدة → إنهاء → إشعار/وميض.
8. سكون الجهاز ثم الإيقاظ: الوقت يعكس الزمن الحقيقي.
9. إنهاء العملية وإعادة الفتح: استعادة المؤقت.
10. فصل Spacedesk ثم وصله: النافذة تنتقل وتعود.
11. وضع الودجت: فوق الكل، قابل للسحب، يحفظ الموضع.
12. صينية النظام: الوقت والقائمة تعملان.
13. اختصارات عامة تعمل والنافذة غير مركّزة.
14. واجهة عربية RTL مع أرقام غربية على الشاشة.
15. استقرار بعد عدة تقلبات؛ لا تعليق واضح.
